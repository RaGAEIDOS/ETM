## 1. Method

1. `Select-String` over every text file in the repository (excluding
   `node_modules/`, `.next/`, `.git/`, `test-results/`, `playwright-report/`,
   `out/`, generated screenshots and binary assets), case-insensitively, for
   `miku` and `ميكو`.
2. A second pass included hidden files/directories and binary extensions were
   skipped explicitly; no Cyrillic or Greek homoglyph variants were found.
3. A filename pass matched `miku` / `ميكو` against every file name (no image
   assets matched; four TypeScript files did).
4. A text pass for pre-rebrand character descriptions, licensing names,
   `system prompt`, `persona` and `personality` located the persona source and
   the old character description, and confirmed there is no LLM endpoint.
5. A separate pass covered `alt=`, `aria-label`, metadata, Open Graph, Twitter
   cards, docs, test fixtures and seeding helpers.
